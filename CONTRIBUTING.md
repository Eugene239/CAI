# Contributing to CAI

Thank you for contributing.

## Before opening an issue or pull request

- Read [AGENTS.md](AGENTS.md), the [project charter](PROJECT_CHARTER.md), and the relevant document in `docs/`.
- Keep all repository content in English.
- Discuss changes to authorization, runner isolation, evidence, provider authentication, or public interfaces before implementing them.

## Pull requests

Pull requests should be small and reviewable. Include:

- the problem and acceptance criteria;
- affected policy and trust boundaries;
- verification performed and its result;
- documentation updates for changed behavior;
- migration or operational consequences, if any.

## Security-sensitive changes

Do not include secrets, access tokens, private source code, webhook payloads, provider credentials, or sensitive run output in issues, commits, or pull requests.

## Current contribution scope

CAI is in its planning phase. Documentation, architecture, threat-model, and developer-experience proposals are welcome. Production code will begin after the initial foundation decisions are accepted.
